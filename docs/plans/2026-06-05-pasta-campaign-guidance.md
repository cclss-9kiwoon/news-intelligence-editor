# Pasta 캠페인 설정 가이던스 + 온보딩

> 목적: 사용자가 "정확히 그 주제만, 소수정예"로 나오게 캠페인을 제대로 설정하도록 안내.
> 핵심 원리: **캠페인 = 좁은 주제 1개. 검색어로 방향 잡고, 주제 정의를 구체적으로 써서 AI가 완전 부합만 통과.**

## 설정 가이던스 (단계별)

### ① 기사 찾기 — 넓게 긁되 방향
- 검색어: 주제 핵심 단어 2~4개. 넓은 단어(엔터/연예) 피하고 구체적으로.
- 포함 키워드: 비워도 됨(주제정의가 진짜 필터). 꼭 그 단어 필요할 때만.
- 제외 키워드: 확실히 뺄 단어(정치/경제/부고).
- 최소 매체 수: 1(단일소스도 씀) / 2(교차검증 빡세게).
- 시간 범위: 24h(신선도). 속보는 더 짧게.

### ② 주제 검수 — 정밀 필터 (가장 중요)
- **주제 정의**: "이 캠페인은 ___ 기사를 쓴다"를 구체적으로.
  - ❌ "K-pop 기사" / ✅ "아이돌 컴백·신곡·앨범 발매. 차트·콘서트 포함. 열애·논란 제외."
  - 구체적일수록 소수정예. AI가 이 기준으로 완전 부합만 통과.
- 제외 주제: 의미로 뺄 것(루머/사생활/주가).

### ③ 기사 작성 — 표현·포맷
- 에디터 역할 + 발행 가이드(톤). 표기 규칙(곡명/앨범 따옴표, 클로징 첨언 금지). 참고 기사 1~3개(문체 학습). 이미지 규격(썸네일 잘림 방지).

### ④ 최종 검수 — 발행 게이트
- 검수 항목 캠페인에 맞게 on(팩트/중복/워터마크/표기). 자동발행 on(통과만 자동)/off(사람 확인).

### LLM (그룹 설정)
- ②④=싼 모델, ③=좋은 모델 → 비용 최적.

## 예시 — "allkpop 컴백 캠페인"
```
검색어: 컴백, 신보, 발매, 타이틀곡
주제정의: K-pop 아이돌/그룹의 컴백·신곡·앨범·미니앨범 발매 소식.
          타이틀곡·뮤비·콘셉트·차트 진입 포함. 열애/논란/사건사고/개인방송 제외.
제외주제: 열애설, 논란, 사생활
최소매체: 1   시간범위: 24h
검수: 표기규칙+워터마크+중복 on / 자동발행: off(처음엔)
```

## 온보딩 (신규 사용자 안내) — 구현 요청
1. **첫 캠페인 생성 시 단계별 안내 흐름**: 그룹 만들기 → AI 키 → 캠페인 만들기 → ①~④ 설정을 짧은 코치마크/스텝으로. 각 단계 "왜 필요한지" 1줄.
2. **빈 상태 안내**: 캠페인 0개일 때 "캠페인 = 기사 종류 1개. 컴백/일상/사건사고처럼 쪼개세요" 안내.
3. **주제 정의 입력칸**: placeholder에 좋은 예시 + ❌/✅ 대비. 비어있으면 "필터 없음 — 너무 많이 들어옵니다" 경고.
4. **건너뛰기 가능** — 숙련자는 스킵.

## 물음표(?) 토글 — 모든 설정 항목
- 각 설정 옆 (?) 호버/클릭 → 짧은 설명 + "이렇게 쓰면 좋아요" 예시.
- 이미 HelpTip 컴포넌트 있음 → 위 가이던스 문구를 각 항목 HelpTip에 반영.
- 특히 ② 주제정의·최소매체수·시간범위·검수항목·자동발행은 필수 설명.

## 분담
- Engineer(UI): 온보딩 흐름(코치마크/스텝) + 빈상태 안내 + 주제정의 placeholder/경고 + 각 항목 HelpTip 문구 보강.
- 피카소: 온보딩/코치마크 비주얼(절제, 건너뛰기).
- 가이던스 문구 = 이 문서 기준.
