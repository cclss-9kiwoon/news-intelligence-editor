# Pasta 캠페인 메인 화면 = 칸반 셸 (좌측 레일 + 보드)

> 설정이 끝난 캠페인에 들어가면 칸반이 메인 화면. 좌측에 캠페인 운영 메뉴(레일)를 두고,
> 우측 본문이 선택한 뷰(보드/현황/발행함/폐기함)로 전환된다.

## 레이아웃

```
┌─ 좌측 레일(~220px, 아이콘 접기 가능) ─┬──────── 본문(선택 뷰) ────────┐
│ 🍝 캠페인명                          │  ▦ 보드 (기본)                  │
│ 그룹명 · ●활성/⏸일시정지             │  기사찾기│주제검수│기사작성│최종검수│
│                                      │  (각 컬럼 접기/펼치기)          │
│ ── 운영 ──                           │                                │
│ ▶ 지금 수집        (진행중 스피너)    │                                │
│ ⏯ 자동 수집 [on/off] · 주기 15/30/60분│                               │
│                                      │                                │
│ ── 보기 ──                           │                                │
│ ▦ 보드                               │                                │
│ 📊 현황                              │                                │
│ 📤 발행함                            │                                │
│ 🗑 폐기함                            │                                │
│                                      │                                │
│ ⚙ 캠페인 설정                        │                                │
│ ← 캠페인 목록                        │                                │
└──────────────────────────────────────┴────────────────────────────────┘
```

## 뷰 정의

### ▦ 보드 (기본)
- 기존 KanbanBoard 재사용.
- **컬럼 접기/펼치기**: 각 컬럼 헤더에 토글. 접으면 세로 라벨 + 건수만(너비 축소).
  접힘 상태는 캠페인별 저장(localStorage). 자동 단계(①~③) 자주 접고 ④에 집중하는 용도.
- 상단 「지금 수집」 버튼/0건 진단 힌트는 레일로 이동(중복 제거) 또는 보드 상단 유지 — 레일 우선.

### 📊 현황 (대시보드)
- 단계별 건수(4단계 카운트).
- 오늘: 생성 N · 발행 N · 폐기 N.
- 검수 통과율(Verified / 최종검수 도달).
- 마지막 수집 시각 + 수집 기사 수.
- 0건 진단(클러스터 거부 사유 — 기존 reasonHint 재사용).

### 📤 발행함
- `published === true` 태스크 목록. 제목 · 발행 시각 · (채널 placeholder — Hydra 연동 자리).
- 신규 필드: `Task.publishedAt?: number`. 발행 액션 시 set.

### 🗑 폐기함
- `discardReason` 있는 태스크. 사유 태그별 그룹(품질부족/주제부적합/중복 등).
- 복원/영구삭제 액션(영구삭제는 confirm).

## 운영 컨트롤

### ▶ 지금 수집
- `refreshNow` 호출(이미 구현). 진행 중 스피너 + 카운트.

### ⏯ 자동 수집 on/off + 주기
- 신규: `Campaign.autoCollect?: { enabled: boolean; intervalMin: 15|30|60 }` (기본 enabled, 30분).
- **off = SearchingPipeline의 신규 태스크 생성 게이트만 멈춤**(RSS 폴링 자체와 분리). 진행 중 태스크는 계속.
- 주기: 폴링 간격에 반영(가능 범위에서). 캠페인별 저장.

## 상태/데이터 변경 (Engineer 판단)
- `Task.publishedAt?: number` 추가.
- `Campaign.autoCollect` 추가 + 마이그레이션 기본값.
- 컬럼 접힘 상태 localStorage 키(캠페인별).
- 라우팅: 캠페인 셸 내부 뷰 state(보드/현황/발행함/폐기함). URL 불필요(SPA 내부 state).

## 범위
- v1 = 셸 + 4뷰 + 컬럼 접기 + 자동수집 토글. 발행 실연결(Hydra)·캘린더는 placeholder.
- 기존 CampaignSettingsPanel은 ⚙설정 진입점으로 유지.

## 검증 기준
- 설정 끝난 캠페인 진입 → 칸반(보드 뷰)이 기본.
- 레일에서 뷰 전환 즉시 반영. 자동수집 off → 새 태스크 안 생김(기존은 흐름 유지).
- 컬럼 접기 상태 새로고침 후 유지.
- tsc 0 · vitest green.
