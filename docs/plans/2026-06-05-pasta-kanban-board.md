# Pasta 칸반 보드 화면 (캠페인 메인)

> 단계 의미는 2026-06-05-pasta-stage-semantics.md 참조. 이 문서는 그 위의 **화면/조작** 기획.
> 화면 비주얼=피카소, 액션 로직=Engineer.

## 전체 레이아웃
좌측 레일(셸: 2026-06-05-pasta-campaign-shell.md) + 우측 보드.

## 상단 리듬 바
```
● 이번 시간 2/3 처리 · 다음 승급 18분 후 · ① 대기 7건 · 수집 84건   [▶ 지금 수집]
```
- 이번 시간 처리수 / maxPerHour
- 다음 승급 가능까지 시간(상한 찼을 때)
- ① 대기 큐 깊이, 수집 기사 수
- 지금 수집 버튼(기존)

## 컬럼별 카드

### ① 기사 찾기 = 대기 큐
- 제목 · 원문 매체 · 서브 N곳
- **골든타임**: 막대(초록→앰버→빨강) + 남은시간 "골든타임 4h 12m"
  - 골든타임 = articleWindow − (now − 기준기사 시각). 0 되면 자동 폐기.
- 정렬: 골든타임 임박순(곧 만료 위로) — 또는 최신순. 임박 경고색.

### ② 주제 검수 / ③ 기사 작성 = 자동
- 진행 상태 + 스피너(② "전문수집 3/4", ③ "초안 작성 중")
- **손잡이 [중단] [우선]**
  - 우선 = 처리 1순위(③ 작성 큐 맨 앞 / ② 승급 우선). 골든타임 임박은 자동 우선 + 수동 토글.
  - 중단 = **보류(멈춤)**. 자동 진행 정지, 현재 단계/컬럼에 "보류" 표시로 남음.
    파이프라인이 보류 태스크는 건너뜀. 카드에 [재개][폐기] → 유저가 나중에 결정.
    재개 = 멈춘 단계부터 다시 진행. (취소·폐기 아님)

### ④ 최종 검수
- Verified(review.passed) → 카드에서 바로 [📤 발행] [✏️ 편집] [🗑 폐기]
- 차단/경고(block/warn) → [검토] 워크스페이스 강제(바로 발행 X)
- 자동발행 on이면 Verified는 이미 자동 발행되어 발행함으로 빠짐(여기 안 남음)

## 데이터/로직 (Engineer)
- 골든타임: 표시·정렬·만료폐기. 기준 = articleWindow vs 기준기사 pubDate(없으면 createdAt).
- `Task.priority?: boolean` — 우선 플래그. 승급·producing 정렬 시 우선 먼저. 골든타임 임박 자동 set.
- `Task.paused?: boolean` — 보류 플래그. 중단 시 set. 파이프라인(②승급/②검수/③작성)이 paused=true면 스킵.
  카드 [재개]→paused 해제(멈춘 단계부터 재개) / [폐기]→폐기함. 보류 중엔 골든타임 만료 폐기 적용 여부는 Engineer 판단(권장: 보류는 만료 면제, 유저 결정 대기).
- ④ 보드 빠른 발행: Verified만 카드에서 publish(기존 훅)+publishedAt. 차단건 버튼 비활성/검토만.
- 리듬바 수치: 최근 60분 처리수, maxPerHour, ① 대기 카운트.

## 비주얼 (피카소)
- 리듬바: 글래스 칩 톤(기존 상태바 계열) + 진행 게이지 느낌.
- 골든타임 막대: 초록→앰버→빨강 그라데이션, 임박 시 펄스.
- ②③ 손잡이: 작게 [중단](뉴트럴/레드 호버) [우선](블루). 카드 hover 시 노출 정도로 절제.
- ④ 액션 버튼: 발행(슬레이트 다크)/편집(인디고 아웃라인)/폐기(레드 텍스트). Verified 그린 배지 유지.
- 컬럼 컬러(①②③ 블루 / ④ 앰버) + 컬럼 접기/펼치기(셸 spec)와 일관.

## 검증
- ① 골든타임 줄고 0에 폐기 / 임박순 정렬 / 우선 토글 시 먼저 처리 / 중단→폐기함 / Verified 보드 발행 / 차단 검토강제 / tsc0·vitest green(로직).
