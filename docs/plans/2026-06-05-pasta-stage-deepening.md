# Pasta 단계 심화 (그룹영향 / ②제작가능 / ③미리보기 / ④검수확장)

> 전체 워크플로 정리 라운드. 그룹→캠페인 영향 + 각 단계 디테일 보강.
> 핵심 = ② 주제 검수를 "쓸 주제 + 실제 제작 가능" 2축으로 구체화.

## G1. 그룹 → 캠페인 영향 (2방향)
- 그룹 = 회사/프로젝트, 큰 단위·방향성(channelType/formality/언어/character...).
- (a) **기본값·예시 제안**: 캠페인 생성/설정 시 그룹 프로필에 맞는 기본 검수규칙·톤·소스·이미지규격 등을 기본값/예시로 제시.
- (b) **결과물 일관성 검수**: ④에서 결과물이 그룹 방향성(톤/character/언어)과 일치하는지 검수 항목으로.

## G2. ② 주제 검수 — 적합성 + 제작 가능성 ⭐최우선
목표: 넓게 수집된 것 중 "진짜 쓸 것 + 실제 만들 수 있는 것" 선별.

### ②-A 적합성
- 설정 키워드/제외/엔티티 부합
- 중복(이미 발행: ownSiteDedupe + 의미중복)
- 핵심 엔티티(인물/그룹/브랜드) 명확
- 제외 주제(AI 판단)

### ②-B 제작 가능성
- 본문 전문 수집 충분(핵심 사실 확보)
- **이미지 ≥ 1 사용가능**(워터마크 없고 규격 충족 = 썸네일 겸용). 많을수록 좋음.
- 0장이면 → **로컬 이미지 라이브러리**서 엔티티 매칭으로 채움.
- 그래도 0 → 보류, 골든타임 만료 시 폐기.

### 판정 3갈래
- 통과(적합 AND 제작가능) → ③
- 보류(자료 대기) → 골든타임 내 재판정
- 컷(부적합 or 영영 이미지 0)

### 로컬 이미지 라이브러리 (Pasta 영역)
- 구조: **그룹 폴더 > 캠페인 폴더**. 나중에 캠페인 간 공유(그룹 레벨 풀).
- 이미지에 **엔티티 태그**(아티스트/그룹) + 규격 메타.
- 매칭: 기사 엔티티(cluster.entities) ↔ 라이브러리 엔티티 태그.
- 업로드/관리 UI + 엔티티 태깅.

## G3. ③ 기사 작성 — 미리보기 + 이미지 규격
- **출력 미리보기**: 현재 설정값으로 "이렇게 써집니다" 샘플 1건 생성(설정 검증용).
- **이미지 규격**: 썸네일 크기/비율 지정(매체 UI서 잘림 방지). 캠페인 설정. ②-B 이미지 사용가능 판정·라이브러리 매칭도 이 규격 기준.
- 더 세밀한 작성 설정 노출.

## G4. ④ 최종 검수 — 결과물 검증 확장
결과물(제작 완료물) 검증. 발행 방식은 맨 끝.
- 그룹~캠페인 설정 부합(G1-b 포함)
- 팩트 정합
- **중복 3종**: ①CMS에 타인이 이미 게시 ②매체 과거 게시물 ③작성 중 stale(사실이 바뀜)
- **SEO/AIEO/구글 정책/신뢰도**: 메타·제목·구조 **자동 점검**. 외부 도구 연동은 **확장 포인트만**(나중 플러그인 자리).
- 통과 후 발행: 사람 vs 자동(자율발행 기획 연계).

## 분담
- Engineer(UI/Context): 그룹기반 기본값 제안 UI, 이미지 라이브러리 관리 UI(그룹>캠페인 폴더·태깅·업로드), ③ 미리보기 버튼·이미지규격 설정, ④ SEO 자동점검 표시 + 확장포인트 stub.
- NIE_개발(로직): ②-B 제작가능 판정(이미지 사용가능 카운트·규격체크·라이브러리 매칭), 중복 3종 검수 로직, SEO/AIEO 자동점검 로직, 결과물 그룹일치 검수.
- 공유: types(Task 제작가능 상태/이미지매칭, 이미지라이브러리 스키마), ReviewResult 확장. 선합의.

## 범위/우선순위
G2(②제작가능+이미지라이브러리) 최우선 → G4(④검수확장) → G3(③미리보기·규격) → G1(그룹영향).
이미지 라이브러리는 v1 = 그룹>캠페인 폴더 + 엔티티 태그 + 매칭. 캠페인 간 공유는 v1.1.
SEO 외부도구 = 확장 포인트만(v1 자동점검까지).
