# 01 — 프로젝트 개요

## 무엇

News Intelligence Editor는 **비개발자 1인 에디터**가 한국 뉴스를 자동 수집해 다국적 콘텐츠 채널에 발행하는 워크플로우를 가속하는 **단일 페이지 브라우저 앱**입니다.

## 왜 — 해결하는 문제

기존 워크플로우의 페인 포인트:

1. **여러 매체 모니터링이 수동** — 에디터가 직접 연합, Soompi, Allkpop 등을 돌면서 새 기사 확인
2. **같은 사건이 매체별로 흩어짐** — 인물 X의 결혼 뉴스가 5곳에서 동시 보도되면 어느 게 정확한지 모름
3. **한국어 → 영문 번역은 매번 ChatGPT/Papago 왔다 갔다** — 컨텍스트 매번 잃음
4. **AI 말투(delve, furthermore 등)가 출력에 섞임** — 발행 직전 또 수동 정리
5. **채널마다 포맷 다름** — 본 사이트는 줄글, X는 트윗 분할, Medium은 마크다운. 매번 새로 작성

## 누구를 위한 것

| 페르소나 | 사용 패턴 |
|---|---|
| **1인 디지털 에디터** | K-pop / 연예 / 가십 기사를 글로벌 영문 매체용으로 변환 |
| **주간지·뉴스레터 에디터** | 일주일치 한국 사건을 영문으로 묶어 발행 |
| **블로거** | 본인 Medium·X에 한국 컨텐츠 분석 게시 |

기술 배경은 가정하지 않습니다 — UI만 보고 사용할 수 있어야 합니다.

## 목표 / 비목표

### 목표

- [x] **수집 자동화** — RSS 다소스 폴링으로 사람 손 거치지 않고 들어옴
- [x] **사건 단위 묶기** — 같은 사건을 다룬 매체들을 한 클러스터로
- [x] **다중 소스 종합** — LLM이 매체 간 교차검증해 한 편의 종합 드래프트 작성
- [x] **사람 검수 단계** — 한국어/영문 모두 textarea에서 직접 편집 가능
- [x] **다국어 채널 출력** — 한국어와 영문 둘 다 본사이트/X/Medium 포맷
- [x] **Provider 자유 선택** — OpenAI / Gemini / 커스텀 OpenAI 호환 endpoint
- [x] **무설치 / 백엔드 없음** — Bolt.new, Vercel, 정적 호스팅 어디든 배포

### 비목표 (의도적 제외)

- ❌ **자동 발행** — X / Medium API 직접 호출, 예약 발행. 검수 단계의 가치를 약화시킴
- ❌ **다중 사용자 / 권한 관리** — 1인 도구 가정. 모든 데이터는 본인 브라우저 localStorage
- ❌ **자체 데이터베이스** — RSS 캐시·이력은 localStorage(20건 FIFO)로 충분
- ❌ **모바일 최적화** — 데스크탑 워크벤치 화면 가정 (좌측 사이드바 + 우측 본문)
- ❌ **다국어 UI** — UI는 한국어 고정 (출력은 KO/EN 모두 지원)

## 가치 명제

"30분 걸리던 사건 1건 종합·다채널 작성을 **5분으로 단축**" — RSS 수집·클러스터링·교차검증·번역·포맷 변환을 모두 자동화하고, 사람은 **검수와 판단**에만 집중.

## 기술 요약

| 항목 | 선택 | 이유 |
|---|---|---|
| 프레임워크 | Vite + React 18 + TypeScript | 빠른 dev 시작, 정적 빌드만으로 어디든 배포 |
| 스타일 | Tailwind CSS 3 + @tailwindcss/typography | utility 우선, 마크다운 prose 렌더 |
| 상태 관리 | React Context (5개) | 작은 도메인, Redux 불필요 |
| 테스트 | Vitest + Testing Library + jsdom | Vite 기본 통합 |
| LLM 통신 | OpenAI 호환 endpoint (fetch) | Provider 추상화, SDK 의존성 최소 |
| RSS 수집 | rss2json (CORS 프록시 + 변환) | 백엔드 없이 다소스 폴링 가능 |
