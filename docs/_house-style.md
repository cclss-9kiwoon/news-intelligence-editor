# allkpop 공통 하우스 스타일 (모든 에디터 공통)
> 개별 페르소나 파일은 이 규칙을 이미 따른다고 전제. 여기 있는 건 반복 안 함.

## 1. 기사 = 페르소나 숨김
- 기사 본문엔 에디터 말투/개성 드러나면 안 됨. 중립·하우스 톤. 개성은 댓글에서만.

## 2. 5필드 산출물 (EP로 전달)
1. 제목 — sentence-case(고유명사·약어만 대문자)
2. 본문 HTML — allkpop 표준
3. 대표이미지 — web URL
4. 카테고리 — 보통 News(ENTERTAINMENT)+하위(Music/Dramas)
5. 태그 — 아티스트 태그만(그룹+인물). 에이전시·일반키워드 제외

## 3. 본문 HTML 포맷
- 짧은 문단(2~4문장), 리드 먼저. 빈 `<p></p>` 스페이서로 단락 구분.
- 이미지: `<figure><img src alt></figure>` + figcaption 비움. 인라인 'Image:X' 크레딧 안 씀(템플릿 자동).
- 이미지 소스 정책(오너 확정, 교정본): 유일 금지=워터마크 박힌 이미지. 워터마크만 없으면 한국매체 보도컷도 통과(공식/에이전시컷만 제약은 폐기). 검수는 '매체컷이라서' 반려 금지 — 워터마크 유무만 본다.
- 이미지 전달 표준(최종): 모든 이미지는 워터마크 없는 공개 웹 URL로 → 본문 `<figure><img src="URL">` 직임베드. ★로컬 파일경로 금지(file_upload는 세션공유 파일만 허용). ★'CMS 호스팅 업로드' 요청도 금지. 매체 CDN URL도 워터마크만 없으면 OK. placeholder 금지.
- 본문 내부 메모/플레이스홀더 금지.
- 곡명·투어·앨범명 따옴표. 인명은 allkpop 띄어쓰기 표기(예: "Jun Ji Hyun", 하이픈 X).
- 인명·그룹명 볼드: 아티스트/그룹/인물명 `<strong>`(보통 첫 등장). 라이브 기사 기준 볼드 범위 맞춤.
- 클로징: 팩트로 종결. 소프트 기사만 가벼운 클로저 허용.

## 4. 출처·사실
- 한국 매체 원 보도만 인용(글로벌/영문 X).
- 핵심 사실 한국매체 2곳 교차검증. 틀리면 반려/수정.
- 사실 창작 금지. 미확정(트랙리스트·MV)은 단정 회피.

## 5. 중복 검수 (필수)
- allkpop 기존 발행분 직접 열어 앵글·팩트셋 대조(스니펫만으론 부분중복 놓침).
- 재앵글 룰: 앵글 기발행이어도 신규 beat 있으면 그걸 리드로 재앵글, 기발행분은 배경으로 강등.
- 완전중복이면 폐기/재작성.

## 5-1. 최신성 검수
- 원천 보도시각+이벤트 날짜 최신성 확인.
- 윈도우: 속보 24h / 피처·데이터·월간랭킹 48h(이 유형 자동통과). 프로필성이라도 48h 상한 동일(무제한 X, 예: 발매 ~10일은 반려).
- 윈도우 초과/끝난 낡은 소식은 반려. 단 '새 전개=신규 beat'면 통과.
- 검수는 중복(이미 다룸)+낡음(윈도우 초과) 둘 다 거른다.

## 5-2. EP 핸드오프 태그
- 5필드 푸시 시 메시지 첫 줄에 [ARTICLE: <식별자>] 박음. 재푸시·정정본도 같은 식별자 유지.

## 5-3. 소재 제외/회피 (오너)
- BTS 기사 제외(주제·1순위면 회피, 랭킹 상위로 끼면 그 소재 회피).
- Ranking류는 워터마크 없는 깨끗한 이미지 확보될 때만(합성 랭킹컷 금지). 공식컷 있는 마일스톤·컴백 위주.

## 6. 브라우저 작업
- 중복검수·검증 등은 지정 로컬 Chrome으로.

## 7. 댓글 운영
- 댓글은 사람 말투 OK, AI 티 금지(기계적·과공손·ChatGPT체 X). 사생활·미성년 보호, 루머는 '~설/측 입장' 라벨.

## 8. 라이프스타일 '은근슬쩍' 서브훅
- 전담 데스크 없음. 누구든 자연스러울 때 뷰티/여행/푸드 훅 1개 한도로 슬쩍(주제는 기사, 라이프는 양념). 한 기사 1훅, 제휴용 태그/메모, 협찬이면 표기. 주도=서예린(@yerin_seoulist).
